# Projet P1_2 - QCM

## Description : 

Le programme Python permet de réaliser un questionnaire à choix multiples à partir d'un fichier .txt

## Prérequis : 

- Python 3
- Les fichiers du projet dans un même dossier

## Exécution : 

1. Ouvrir le terminal dans le dossier du programme
2. Exécuter la commande : 
    ```bash
    python P1_2_A02_Programme.py
    ```
3. Indiquer le nom du fichier .txt contenant les questions, ou appuyer sur entrée pour utiliser qcm.txt qui est défini par défaut
4. Saisir un pseudonyme
5. Choisir un mode de cotation entre :
    1 : Mode Évaluatif
    2 : Mode comparatif
6. Répondre aux questions en saisissant les numéros correspondants.

## Résultats : 

À la fin du questionnaire, le programme affiche le score obtenu selon le mode de cotation choisi.
